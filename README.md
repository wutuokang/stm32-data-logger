# STM32 多通道数据采集与监控终端

基于 STM32F103C8T6 的长时间数据记录设备：多路模拟量采集、数字滤波、掉电保护存储、串口导出。

硬件：

| 模块 | 型号 | 接口 |
| 主控 | STM32F103C8T6 | — |
| 显示 | SSD1306 OLED 128×64 | 软件 I²C |
| 温湿度 | DHT11 | 单总线 |
| 六轴 | MPU6050 | 软件 I²C |
| 光照 / 温度 | 光敏 / 热敏模块 | ADC1 双通道 |
| 存储 | W25Q64 8MB | 软件 SPI |
| 电机 | TB6612 | PWM + 方向 |
| 其他 | 蜂鸣器、4 路 LED | GPIO |

引脚分配：

| 引脚 | 用途 | 引脚 | 用途 |
| PA0 / PA1 | ADC 热敏 / 光敏 | PB0 | 蜂鸣器 |
| PA2 / PA3 | USART2 TX / RX | PB5 | W25Q64 片选 |
| PA4 ~ PA7 | 板载 LED ×4 | PB6 / PB7 | I²C SCL / SDA |
| PA11 | DHT11 | PB8 | W25Q64 时钟 |
| PA12 / PA15 | 按键 ×2 | PB9 | 风扇 PWM |
| PA13 / PA14 | SWD 调试口（保留） | PB10 / PB11 | 风扇方向 |
| | | PB12 / PB13 | W25Q64 MISO / MOSI |

未占用：PA8~PA10、PB1~PB4、PB14/PB15、PC13~PC15

`Encoder.c`（旋转编码器）为预留模块，EXTI0 引脚与蜂鸣器冲突，当前未启用。

主要功能

调度：TIM2 提供 1ms 时基，主循环按 `if (now - tLast >= 周期)` 轮询 9 个任务，
周期覆盖 5ms（ADC）到 60s（元数据保存）。

采集滤波：ADC1 双通道扫描 + DMA 循环搬运；10 点滑动平均滤波（环形缓冲 + 写指针轮转）。
输入稳定时，采样波动范围由 13 LSB 收敛至 2 LSB（串口输出滤波前后 10 秒极值差验证）。

掉电保护存储：W25Q64 分数据区（环形缓冲）和元数据扇区两部分。

- 一个扇区（4KB）擦一次写满 256 条，避免频繁擦除
- 页编程不能跨页，超页时跳到下一页开头
- 每条记录用 `guard` 标志保护：先写 `0xFF`，整条写完再改写 `0x5A`
- 写指针和条数存元数据扇区，带 `magic` 和 `checksum` 校验，上电恢复
- 进入新扇区前先保存元数据（擦除会清空该扇区）

传感器：DHT11 关中断保护微秒时序；MPU6050 原始值按灵敏度换算成 g 和 °/s。

交互与控制：OLED 四级菜单 + 按键切换；风扇按温度/湿度/热敏三条件分级调速；
LED 随光照分档补光。

 实测

| 项目 | 数值 |

| 连续记录 | 1.9 小时 |
| 记录条数 | 13623 条 |
| 丢失 | 0 条 |
| 采样周期 | 500ms |
| 地址校验 | 记录数 × 16 = 写地址 |

导出 CSV 后用 Excel 绘制趋势曲线验证数据连续性。

结构

    main.c        主程序：任务定义、调度、数据导出
    Module/       驱动：ADC、Storage、W25Q64、OLED、DHT11、MPU6050、FAN、LED、按键等
    System/       延时（SysTick）
    User/         中断服务函数与库配置
    Start/        启动文件
    Library/      STM32F10x 标准外设库

说明

驱动均为本人独立实现，部分底层时序参考公开例程（oled、delay）后按自身需求改写。

已知不足：元数据只用单扇区（极端掉电会退回从头写）；DHT11 读取失败时无有效性标志。
